# Firebase Rules History / تاريخ قواعد Firebase

- `../../../firestore.rules` (من جذر هذا المجلد إلى أعلى المشروع) هو ملف القواعد المحلي الذي تحدده `firebase.json`.
- `candidates/` يحتوي مرشحات موحدة/تجريبية محفوظة للتاريخ فقط.
- `snapshots/` يحتوي نسخًا مرجعية سابقة.
- `backups/` يحتوي نسخًا احتياطية عند وجودها.

هذه الملفات ليست بدائل تلقائية لملف `firestore.rules`، ولا تثبت أن محتواها منشور في Firebase Console. لا تحذفها باعتبارها مكررة ولا تنشرها من تلقاء نفسها.
