# QA / Test Assets

هذا المجلد مخصص لأدوات الفحص المساعدة، وليس جزءًا من تشغيل التطبيق. لم يتم تشغيل أي اختبار في عملية التنظيم.

- `node-tests/identity/`: فحوص مرجعية لهوية Firebase وبصماتها.
- `node-tests/rules/`: فحوص ساكنة تربط بعض خصائص التطبيق بملف القواعد.
- اختبارات Android التي يديرها Gradle محفوظة في `app/src/test/` و`app/src/androidTest/` حسب متطلبات Android.
